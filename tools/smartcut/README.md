# Умная вырезка белого персонажа с белого фона (танец FreijaFoxy)

Скрипты разовые (пути — к рабочей папке с кадрами), сохранены как рецепт.

1. `cutn.py` — вырезка по цвету: фон Seedance ровный и нейтральный, мех тёплый и темнее.
2. `bir2.py` — нейросеть BiRefNet (rembg `birefnet-general`, onnxruntime без кеша памяти: ~18 с/кадр, 8 ГБ).
3. `smart.py train` — классификатор пикселей (sklearn HistGradientBoosting) учится на хороших кадрах:
   исправленный вручную f001 (`src-sheets/seedance/freija_dance_f001_fixed.png`) и f114.
   Признаки: цвет, нейтральность, локальная яркость/разброс, близость к тёмному контуру, ответы BiRefNet и цветовой вырезки.
4. `predict.py a b` — применяет модель; голова с ушами переносится из хорошего кадра по движению головы
   (ECC affine по лицу), светлые клочки, касающиеся фона без контура, убираются.

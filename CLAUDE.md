# CLAUDE.md — контекст проекта для Claude Code

Клип на песню «Can I Sleep with You Tonight?». Gumdong — имя вокалистки (и репозитория); у клипа пока нет названия. HTML5-плеер рисует кадр как чистую функцию времени `renderAt(T)`; видео рендерится из него в самом конце. Устройство репозитория — в README.md, раскадровка и список ассетов — в docs/storyboard.md. Здесь — решения, договорённости и находки, которых там нет.

## Решения по клипу

- **Формат:** 16:9, 1920×1080. Сейчас делаем **первую минуту** (0:00–1:11 песни, звук не режем; финал — блэкаут на 1:05.8, тёмный экран, звук быстро затухает 1:05.8→1:11 — `CLIP.audioFade`, плеер и render.js). Полная песня 3:40 — возможное продолжение позже.
- **Стиль:** аниме/фурри-персонажи, 2D-спрайты в псевдо-3D клубе; поверх всего лёгкая пиксельная сетка (`CLIP.post.pixel = 3`), зерно, сканлайны — чтобы скрыть несовершенство генераций и склеить разные источники.
- **Сеттинг:** маленький андеграундный клуб «для избранных», зрители сидят за столиками со свечами. Зал целиком не показываем.
- **Идея:** текст — детский страх («mom, can i sleep with you tonight?»). Клуб постепенно оказывается тем самым кошмаром: зрители неподвижны, у теней загораются глаза, к концу зал гаснет и остаётся вокалистка в луче.
  Вокалистка взрослая; **флешбэков с ребёнком/«мамой» нет** — история только через клуб и группу.
- **Титр:** у клипа пока нет названия; надпись в сцене 02 убрана по просьбе пользователя — титров сейчас нет.
- **Персонажи** (листы в `src-sheets/`; в коде id персонажа = имя, файлы спрайтов начинаются с имени):
  - **Gumdong** — вокал и гитара (чёрная волчица, ошейник с шипами) → `gumdong`. **Играет левой рукой** (гриф в правой руке) — во всех позах и роликах она левша, спрайты не отзеркаливать.
  - **Rossali** — бас (лавандовые волосы) → `rossali`. **Сигарета — только на крупных планах** (портрет `rossali_portrait`), в общих позах и роликах без неё.
  - **Lupa** — ударные (рысь-кошка, фиолетовые волосы) → `lupa` (на листе опечатка «Luna» — правильно Lupa). В клубе стоит спрайтом `lupa_kit` вместе со своей установкой (установка кодом убрана).
  - Maeve (красная панда) — **зритель** за столиком → `maeve`. Сидит на стуле-образце (`maeve_sit`), со стороны входа от своего столика t1 — из зала (со сцены) столик закрывает ноги.
- **Стул-образец** `assets/sprites/chair.png` (`src-sheets/chair_src.png`) — **один для всех зрителей**: каждого нового зрителя генерировать сидящим на нём (прикладывать картинку стула). Вид сзади позы — `back` у позы; движок сам берёт его, когда камера у зрителя за спиной (CAM.z < z зрителя: сцены 01, 05).
  - Alex — **зритель за столиком, сидит на стуле-образце** (решение пользователя: не танцует) → `alex`. Нужны: крупный план с «V» (заменит его кроп на «again» в сцене 07), сидя спереди / сзади / сбоку (профиль — для проходов камеры сбоку, вторая сторона — зеркалом).
- **Базовые изображения для генерации** (ChatGPT и Seedance): для общих и средних планов Gumdong и Rossali всегда с инструментом — `src-sheets/gumdong_guitar_src.png` и `src-sheets/rossali_bass_src.png`. Новые позы и ролики делать от них, чтобы гитары совпадали (у Gumdong — чёрный Les Paul, один ремень через плечо; у Rossali — чёрный 4-струнный бас). Листы персонажей — для крупных планов и деталей.
- Будут ещё зрители — **каждый уникальный, не размножать и не перекрашивать**. Тени `ghost` в `SET.ents` — места-заглушки под них.
- **Генерация ассетов:** спрайты делает пользователь в ChatGPT по листам; короткие анимации — в Seedance 2.0, потом переводим в спрайты (кадры 24 fps → вырезка фона → crop по общему bbox всех кадров → лист). Первый кадр для Seedance — готовый спрайт; конец ролика должен совпадать с началом (цикл) или с позой следующей сцены.

## Договорённости по работе

- Репозиторий публичный: `duglaskele-lab/Gumdong-tonight-clip`. Просмотр — GitHub Pages с ветки `main` (пользователь включает в Settings → Pages; если ещё не включено — напомнить). Возможна работа нескольких человек.
- Сцены: `clip/scenes/NN-name.js` — **номер + короткое имя** (выбор пользователя). При вставке сцены в середину номера можно сдвинуть, но тогда переименовать файлы и `CLIP.scenes` согласованно. Номер в разговоре может разойтись на 1 — сверяться по времени и содержанию, в ответе называть время.
- **Новые ветки на GitHub не создавать** (просьба пользователя; если понадобится — попросит отдельно). Работаем в `main`; в сообщении коммита — «сцена NN, время, что изменено».
- Pull requests в этом проекте можно одобрять и мерджить; спрашивать пользователя, если правка что-то удаляет или кардинально меняет.
- Перед публикацией правок — проверить кадры (`tools/frames.js`, см. ниже). Видео не рендерить без просьбы.
- Пользователь говорит по-русски, опыта в монтаже клипов нет — объяснять просто, предлагать 2–3 варианта с ценой (какие ассеты нужны), если просит «подумать».

## Правила визуала (из опыта похожих клипов)

- Камера не «бьёт» в долю (наезд-отъезд убран по просьбе пользователя) — вместо этого лёгкое покачивание кадра вверх-вниз в такт: `bob: px` у сцены (7–12 px).
- Не делать стробоскоп: вспышка/негатив/белый кадр — одиночный акцент на склейке, не серия.
- Персонаж не прыгает между соседними сценами: то же место и размер; смена позы — растворением, а не склейкой.
- Обрезанный край спрайта уводить за край кадра (камерой/масштабом), сам спрайт не резать; «фокус на детали» — наездом камеры.
- Каждой части песни — свой узнаваемый режим (палитра + раскладка + стиль текста); при повторе части режим возвращается.
- Подписи — белые буквы с чёрной обводкой (уже в `drawCaption`). Кинетический текст — только на ключевых словах/хуках.
- Персонажей не обесцвечивать (ч/б) без просьбы; затемнение — тёмным слоем.
- Только `rand(i)`, никакого `Math.random()` — иначе видео мерцает. Частицы и анимации — функции времени, без накопленного состояния.

## Технические находки

- **Тайминг песни:** 143.555 BPM, первая доля 0.186 с, доля ≈ 0.418 с; `b(k)` в config.js = время доли k. Сцены начинаются/кончаются на долях.
- **Реальные фразы вокала** (по отделённому голосу; распознавание Whisper ошибалось на 1–1.5 с — ему не верить):
  13.84 «i'm really scared» · 15.6–22.5 «mom, can i sleep…» · 24.16–29.2 «it's not a nightmare…» · 29.98–32.6 «i'm really scared» · 33.66–38.9 «mom, can i sleep…» · 39.1–46.6 again×N · 47.0–52.0 «can i sleep…» · 52–60.6 проигрыш · 60.6–65.8 припев «can i sleep…». Мелкие правки — инструментом Sync lyrics (клавиша L) в плеере.
- **«Again»:** шаг склеек 0.72 с от 39.15 (`AG0/AGD` в сцене 07) — выставлен на глаз, вероятно нужно подогнать по звуку. Слов «again» в этой фразе, похоже, больше 10.
- **Липсинк:** `assets/data/vox_env.js` — огибающая слогов (30 fps) из отделённого голоса. Пересчёт: `python3 tools/analyze.py assets/audio/song.mp3 vocals.flac`.
  - Отделение голоса: `pip install "audio-separator[cpu]" audioread`, модель `UVR-MDX-NET-Voc_FT.onnx` — встроенная загрузка падала (504), скачивать вручную: `https://github.com/TRvlvr/model_repo/releases/download/all_public_uvr_models/UVR-MDX-NET-Voc_FT.onnx` в папку и запускать с `--model_file_dir`.
  - **Нарисованные рты:** у позы `mouths: [закрыт, приоткрыт, А, О]` (ключи ассетов) → при `mouth: true` движок подменяет картинку (`mouthIdx`: тихо — закрыт, средне — приоткрыт, громкий слог — «А» или «О» по хешу начала слога). Сейчас: позы `scared` и `q34` у Gumdong. Без `mouths` — старый рот кодом (`drawMouth`, овал) по `mouth: {x, y, w}`.
- **Анимации из Seedance:** `ANIM_FILES` в config.js (`dir`, `frames`, `fps`, `loop`) → кадры `fNNN.webp` грузятся в `E.anim`; поза `{ key, anim: 'имя' }` проигрывает их по абсолютному времени T (цикл непрерывен между сценами). Сдвиг/скорость — `animOffset` (сек), `animSpeed` у слоя/объекта, напр. `animOffset: -b(144)` = с первого кадра в начале сцены 10.
- **Камера: знак pitch** — минус = смотреть вниз, плюс = вверх. Масштаб персонажа-билборда считается по глубине середины тела (раньше по ступням — при наклоне вниз персонаж «уменьшался»).
- **Плавная камера:** `cam.smooth: .6` у сцены — одна кривая Catmull-Rom через все ключи (`splineAt`), мягкий разгон/торможение только в начале и конце; без него каждый отрезок между ключами со своим ease, и камера замирает на промежуточных точках. Сейчас в сцене 09.
- **Процедурный рот поверх спрайта с открытым ртом:** `mouth.cover: {rx, ry}` (в ширинах рта) — нарисованный рот закрашивается цветом кожи `mouth.lip`, в тишине рисуется закрытый рот линией (поза `mic`, сцена 08). **На анимации** — положение рта по кадрам в `assets/data/anim_track.js` (`ANIM_TRACK[имя] = [[x,y],…]`, считано template matching лица от кадра 0), поза `playSing` (S1), сцена 10.
- **Силуэт:** у объекта в клубе `sil: 0..1` + `silColor` — заливка цветом поверх спрайта, `glow: {color, blur}` — свечение, `alpha`. В `set` сцены `hide`, `ents`, `add` могут быть функциями `(lt, T)` — меняются по ходу сцены (финал сцены 11).
- **Поза «по пояс» в 3D-клубе:** `part: .6` у позы — картинка покрывает верхние 60 % роста, низ висит в воздухе → камеру держать так, чтобы срез был за кадром (сцена 08).
- **Вырезка с белого фона (ChatGPT, Seedance)** — `python3 tools/whitecut.py src.png out.png`: фон от краёв + мягкий край с очисткой от белого (нет каймы, кончики волос целы); замкнутые просветы — по подсказке rembg, а для кадров видео `--holes 20` (rembg не видит просвет между рукой и телом); `--wm x0,y0,x1,y1` — закрасить водяной знак; `--no-crop` — для кадров анимации (crop потом по общему bbox). Рты для липсинка: варианты выравниваются по лицу (cv2 ECC, локально у рта), рот вклеивается в базовую картинку с растушёвкой и подгонкой цвета кожи → картинки отличаются только ртом.
- **Seedance обрезает края**, если пропорции первого кадра не совпадают с видео (картинка 4:5 → видео 3:4 теряет ~3 % с каждого бока). Перед генерацией дополнять кадр белыми полями до 3:4. Сдвиг кадров видео относительно исходника находится подбором (S3: масштаб 1112/1280, сдвиг 31 px) — так кадры переносятся в рамку статичного спрайта и переход статика → анимация незаметен.
- **Ролик с отъездом камеры** (L2: Seedance отдалил кадр, масштаб 0.89 + сдвиг ~40 px): сдвиг находится cv2 ECC (affine) первого кадра к исходнику, кадры пересчитываются в рамку статичного спрайта (премультиплицированный warp). У L2 рамка выросла сверху (палочки) — `lupa_kit.png` дополнен прозрачным сверху до той же рамки, `scale` позы пересчитан (.86 → .903). Блики на хроме барабанов похожи на просветы фона — после вырезки мелкие замкнутые дырки (<250 px) возвращаются.
- **Не белый фон в ролике** (S3: серый градиент + лучи): альфа от rembg `isnet-anime`, край очищается от цвета местного фона (размытое среднее фоновых пикселей) — скрипт был разовый, логика как в whitecut.
- **Вырезка с листов** (`python3 tools/cut_sprites.py src.png out.png [--box x0,y0,x1,y1] [--rembg-only]`): фон листа берётся по цвету от краёв (flood fill), rembg `isnet-anime` — только как оболочка (дилатированная маска с залитыми дырами), чтобы срезать сетку/подписи листа и не съесть внутренность ушей. Для листа на пёстром фоне (sheet4, розовые звёзды) — чистый rembg. Проверять вырезку на пурпурном фоне.
- **Инструменты:** у Gumdong и Rossali — в спрайтах (позы `guitar` / `bass`). Барабанная установка и микрофонная стойка рисуются кодом (`ENT.drums`, `ENT.mic` в world.js). Гитара-заглушка кодом (`inst` у позы) осталась только для поз с листа без инструмента.
- **Микрофон** (стойка кодом) — слева от неё, как в спрайтах у микрофона: стойка x −0.2, штанга `boom` 0.12 м к губам, микрофон чуть ниже рта (h 1.27 — камера часто снизу, иначе закрывает глаза); в сценах 08 и 11 спрятан — там стойка нарисована в спрайте `gumdong_mic`.
- **Проверка кадров:** `python3 -m http.server 8765` в корне, затем `node tools/frames.js out.jpg 12 30.5 45` → лист кадров 3×N. Для движения — снимать 12–24 кадра с шагом 1/12 с. `?render&t=…` — один кадр без UI.
- **Быстрая загрузка (плеер):** спрайты грузятся из `assets/sprites/web/*.webp` (в 9 раз легче PNG) — **после замены/добавления спрайта запускать `python3 tools/webify.py` и поднимать `CLIP.ver`** (иначе покажется старая картинка; нет webp — берётся PNG). Песня для плеера — `assets/audio/song_clip.mp3` (первые 1:15, `-c copy`), полная — `song.mp3`. Плеер стартует после спрайтов и шрифтов; кадры анимаций догружаются в фоне, только используемые в сценах (`usedAnims`), пока кадра нет — рисуется статичный спрайт позы. `?render` ждёт всё. `sw.js` (service worker) кеширует sprites/anim/fonts в браузере по URL с `?v=CLIP.ver`; скрипты всегда из сети.
- **GitHub Pages:** публикация «из ветки» падает по таймауту (10 мин), если файлов слишком много → `_config.yml` (Jekyll) исключает с сайта `src-sheets`, `tools`, `docs`, `song.mp3`, PNG спрайтов (плеер берёт webp) и неиспользуемые анимации. **Новую анимацию, которая не используется, добавлять в exclude; начали использовать — убрать оттуда.** Статус публикаций — Actions → pages build and deployment.
- **Шрифты** лежат в `assets/fonts` (не Google Fonts) — рендер не зависит от сети.
- **Рендер видео:** `node tools/render.js clip.mp4 24` или Actions → Render video. Ещё ни разу не запускался — при первом запуске проверить.

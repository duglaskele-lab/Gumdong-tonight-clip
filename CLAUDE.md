# CLAUDE.md — контекст проекта для Claude Code

Клип на песню «Can I Sleep with You Tonight?» (группа Gumdong). HTML5-плеер рисует кадр как чистую функцию времени `renderAt(T)`; видео рендерится из него в самом конце. Устройство репозитория — в README.md, раскадровка и список ассетов — в docs/storyboard.md. Здесь — решения, договорённости и находки, которых там нет.

## Решения по клипу

- **Формат:** 16:9, 1920×1080. Сейчас делаем **первую минуту** (0:00–1:07.5 песни, звук не режем, финал — блэкаут + затемнение на гитаре). Полная песня 3:40 — возможное продолжение позже.
- **Стиль:** аниме/фурри-персонажи, 2D-спрайты в псевдо-3D клубе; поверх всего лёгкая пиксельная сетка (`CLIP.post.pixel = 3`), зерно, сканлайны — чтобы скрыть несовершенство генераций и склеить разные источники.
- **Сеттинг:** маленький андеграундный клуб «для избранных», зрители сидят за столиками со свечами. Зал целиком не показываем.
- **Идея:** текст — детский страх («mom, can i sleep with you tonight?»). Клуб постепенно оказывается тем самым кошмаром: зрители неподвижны, у теней загораются глаза, к концу зал гаснет и остаётся вокалистка в луче.
- **Персонажи** (листы в `src-sheets/`):
  - sheet1 — **вокалистка с гитарой** (чёрная волчица, ошейник с шипами) → `vox`
  - sheet2 — **басистка** (лавандовые волосы, сигарета) → `bass`
  - sheet3 — **барабанщица** Luna (рысь-кошка, фиолетовые волосы) → `drum`
  - sheet4 — Maeve (красная панда), **зритель** за столиком → `maeve`
  - sheet5 — Alex, **зритель, танцует у сцены** → `alex`
  - Будут ещё зрители — **каждый уникальный, не размножать и не перекрашивать**. Тени `ghost` в `SET.ents` — места-заглушки под них.
- **Генерация ассетов:** спрайты делает пользователь в ChatGPT по листам; короткие анимации — в Seedance 2.0, потом переводим в спрайты (кадры 24 fps → вырезка фона → crop по общему bbox всех кадров → лист). Первый кадр для Seedance — готовый спрайт; конец ролика должен совпадать с началом (цикл) или с позой следующей сцены.

## Договорённости по работе

- Репозиторий публичный: `duglaskele-lab/Gumdong-tonight-clip`. Просмотр — GitHub Pages с ветки `main` (пользователь включает в Settings → Pages; если ещё не включено — напомнить). Возможна работа нескольких человек.
- Сцены: `clip/scenes/NN-name.js` — **номер + короткое имя** (выбор пользователя). При вставке сцены в середину номера можно сдвинуть, но тогда переименовать файлы и `CLIP.scenes` согласованно. Номер в разговоре может разойтись на 1 — сверяться по времени и содержанию, в ответе называть время.
- Правки — в ветке + pull request с описанием «сцена NN, время, что изменено»; мелкие правки по прямой просьбе — можно в main.
- Перед публикацией правок — проверить кадры (`tools/frames.js`, см. ниже). Видео не рендерить без просьбы.
- Пользователь говорит по-русски, опыта в монтаже клипов нет — объяснять просто, предлагать 2–3 варианта с ценой (какие ассеты нужны), если просит «подумать».

## Правила визуала (из опыта похожих клипов)

- Не делать стробоскоп: вспышка/негатив/белый кадр — одиночный акцент на склейке, не серия.
- Персонаж не прыгает между соседними сценами: то же место и размер; смена позы — растворением, а не склейкой.
- Обрезанный край спрайта уводить за край кадра (камерой/масштабом), сам спрайт не резать; «фокус на детали» — наездом камеры.
- Каждой части песни — свой узнаваемый режим (палитра + раскладка + стиль текста); при повторе части режим возвращается.
- Подписи — белые буквы с чёрной обводкой (уже в `drawCaption`). Кинетический текст — только на ключевых словах/хуках.
- Персонажей не обесцвечивать (ч/б) без просьбы; затемнение — тёмным слоем.
- Только `rand(i)`, никакого `Math.random()` — иначе видео мерцает. Частицы и анимации — функции времени, без накопленного состояния.

## Технические находки

- **Тайминг песни:** 143.555 BPM, первая доля 0.186 с, доля ≈ 0.418 с; `b(k)` в config.js = время доли k. Сцены начинаются/кончаются на долях.
- **Реальные фразы вокала** (по отделённому голосу; распознавание Whisper ошибалось на 1–1.5 с — ему не верить):
  13.84 «i'm really scared» · 15.6–22.5 «mom, can i sleep…» · 24.16–29.2 «it's not a nightmare…» · 29.98–32.6 «i'm really scared» · 33.66–38.9 «mom, can i sleep…» · 39.1–46.6 again×N · 47.0–52.0 «can i sleep…» · 52–60.6 проигрыш · 60.6–65.8 припев «can i sleep…». Мелкие правки — инструментом Sync lyrics (клавиша L) в плеере.
- **«Again»:** шаг склеек 0.72 с от 39.15 (`AG0/AGD` в сцене 07) — выставлен на глаз, вероятно нужно подогнать по звуку. Слов «again» в этой фразе, похоже, больше 10.
- **Липсинк:** `assets/data/vox_env.js` — огибающая слогов (30 fps) из отделённого голоса. Пересчёт: `python3 tools/analyze.py assets/audio/song.mp3 vocals.flac`.
  - Отделение голоса: `pip install "audio-separator[cpu]" audioread`, модель `UVR-MDX-NET-Voc_FT.onnx` — встроенная загрузка падала (504), скачивать вручную: `https://github.com/TRvlvr/model_repo/releases/download/all_public_uvr_models/UVR-MDX-NET-Voc_FT.onnx` в папку и запускать с `--model_file_dir`.
  - Рот сейчас рисуется кодом (`drawMouth`, овал поверх) — заглушка. План: 4 нарисованных рта (закрыт/приоткрыт/А/О) на портрет, выбор по уровню `voxOpen(T)`. Координаты рта — `mouth: {x, y, w}` в долях картинки в `CHARACTERS` (для vox_front, vox_face, vox_face34 уже выставлены).
- **Вырезка спрайтов** (`tools/cut_sprites.py`): фон листа берётся по цвету от краёв (flood fill), rembg `isnet-anime` — только как оболочка (дилатированная маска с залитыми дырами), чтобы срезать сетку/подписи листа и не съесть внутренность ушей. Для листа на пёстром фоне (sheet4, розовые звёзды) — чистый rembg. Проверять вырезку на пурпурном фоне.
- **Инструменты** (гитары, бас, барабаны, микрофон) пока нарисованы кодом поверх спрайтов с опущенными руками — заменить, когда появятся позы с инструментами.
- **Проверка кадров:** `python3 -m http.server 8765` в корне, затем `node tools/frames.js out.jpg 12 30.5 45` → лист кадров 3×N. Для движения — снимать 12–24 кадра с шагом 1/12 с. `?render&t=…` — один кадр без UI.
- **Шрифты** лежат в `assets/fonts` (не Google Fonts) — рендер не зависит от сети.
- **Рендер видео:** `node tools/render.js clip.mp4 24` или Actions → Render video. Ещё ни разу не запускался — при первом запуске проверить.

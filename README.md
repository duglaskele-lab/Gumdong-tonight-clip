# Gumdong — «Can I Sleep with You Tonight?» · клип

HTML5-клип из 2D-спрайтов в псевдо-3D клубе. Весь клип — это страница `index.html`, которая рисует кадр как функцию времени; видео рендерится из неё в самом конце.

**Смотреть:** GitHub Pages этого репозитория (Settings → Pages). Ссылка на конкретный кадр: `…/?t=0:41`.
Клавиши: Space — play/pause, ←/→ — 2 с, Shift+←/→ — кадр, `[` `]` — сцены, N — метки прототипа, D — инфо, L — подгонка текста песни.

## Структура

```
index.html            плеер: таймлайн, перемотка, подгонка текста (Sync lyrics), ?t=…
engine/               движок — меняется редко
  core.js             время, ключевые кадры, рендер, пост (пиксели, зерно, глитч, VHS), подписи, липсинк
  world.js            3D-камера и клуб: стены, сцена, столики, свет, прожекторы, барабаны, микрофон
  layers.js           экранные слои: фоны, крупные планы, кинетический текст, титры
clip/
  config.js           темп, ассеты, персонажи (позы, рот), текст песни, декорации клуба (SET)
  scenes/NN-name.js   одна сцена = один файл
assets/
  sprites/            вырезанные PNG персонажей
  anim/               циклы из Seedance (листы спрайтов)
  bg/                 фоны
  audio/song.mp3
  data/vox_env.js     громкость голоса для липсинка (генерируется tools/analyze.py)
  fonts/
src-sheets/           исходные листы персонажей
tools/                вырезка фона, анализ песни, проверка кадров, рендер видео
docs/storyboard.md    раскадровка и список нужных ассетов
```

## Как добавить или поправить сцену

1. Файл `clip/scenes/NN-name.js` (номер + короткое имя), внутри — вызов `scene({...})`. Вспомогательные константы — внутри блока `{ }`, чтобы не пересекаться с другими файлами.
2. Добавить имя файла в `CLIP.scenes` в `clip/config.js`.
3. Время — абсолютное, удобнее в долях: `b(29)` = начало 29-й доли. Время ключей камеры и слоёв — от начала сцены.

Сцена бывает «мировой» (`world: true` + `cam.keys` в метрах: x, y, z, yaw, pitch, roll, fov) — тогда рисуется клуб из `SET`,
а `set: { hide, ents, add, light }` меняет декорации и свет только в этой сцене. Или «экранной» — только `layers` (фон + крупный план).

## Как добавить персонажа или позу

1. Положить PNG с прозрачным фоном в `assets/sprites/` (вырезать с листа: `tools/cut_sprites.py`).
2. Ключ в `ASSETS`, поза в `CHARACTERS` (`mouth: {x, y, w}` — где рот, в долях картинки, если нужен липсинк).
3. Поставить в клуб: объект в `SET.ents` (`type: 'char'`, `seat` — для сидящих: какая доля спрайта сверху видна над столиком).

## Правила

- Никакого `Math.random()` — только `rand(i)`, иначе видео будет мерцать.
- Правки — в ветке и через pull request; в описании — номера сцен и время.
- Проверка кадров: `python3 -m http.server 8765` и `node tools/frames.js out.jpg 12 30 45` (нужен Playwright).

## Рендер видео

`node tools/render.js out.mp4` (локально, нужны Playwright и ffmpeg) или вкладка **Actions → Render video → Run workflow** — готовый MP4 появится в артефактах прогона.
